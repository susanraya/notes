### EPIC-001 · approved · source: planning:EPIC-001

Each person registers and signs in with an email and password to a personal account; all notes are private to the owning account. Free to use, no payments/billing in scope.

Session security is stated as checkable outcomes (sessions expire, signing out ends the session, passwords stored hashed) without prescribing a mechanism.

**Related:** US-001, US-002, US-003, US-004

### EPIC-002 · approved · source: planning:EPIC-002

Users create and edit rich-text notes with formatting (bold, lists, headings), saved automatically via autosave as they type.

No image or file attachments are in the initial scope; stated as an assumption on the editor.

**Related:** US-005, US-006, US-007

### EPIC-003 · approved · source: planning:EPIC-003

The note list is the home screen after sign-in, showing the user's own notes, with the ability to delete a note.

Standard CRUD is completed by create/edit (covered in EPIC-002) and delete here.

**Related:** US-008, US-009

### EPIC-004 · approved · source: planning:EPIC-004

Users organise their notes using tags or folders so related notes can be grouped and found.

Applies to the signed-in user's own notes only.

**Related:** US-010, US-011

### EPIC-005 · approved · source: planning:EPIC-005

Users find their notes again by searching across their own notes by content or title.

Search is restricted to the signed-in user's own notes.

**Related:** US-012

### EPIC-006 · approved · source: planning:EPIC-006

The application is delivered as a responsive web app usable in any modern browser on laptop or phone while online.

No offline support and no native apps are in scope; stated as assumptions on delivery.

**Related:** US-013
